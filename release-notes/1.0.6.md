## 変更点

- **新しいバージョンの確認を、gigowat の Mac アプリ共通のしくみに揃えました**。版の情報は gigowat.com の一覧から読み込みます。インストールする前に、ダウンロードしたファイルの照合（SHA-256）を加えました。これまでどおり、同じ開発者の Developer ID 署名と Apple の公証も確かめます
- ダウンロード中は進み具合を表示し、途中で取り消せます
- 使い方は変わりません。設定画面の「起動時に新しいバージョンを確認」をオフにすると、通信は一切行いません。[プライバシーポリシー](https://elgotune.gigowat.com/privacy.ja.html)も合わせて更新しました

1.0.5 からは、起動するとこの版を案内します。

Developer ID 署名・Apple 公証済み。ダウンロード後そのまま開けます。

## Changes

- **The update check now uses the same mechanism as gigowat&rsquo;s other Mac apps.** It reads the version list on gigowat.com, and the download is now matched against its SHA-256 before installing, in addition to the existing Developer ID and notarization checks
- Download progress is shown and can be cancelled
- Nothing else changes. Turn off &ldquo;Check for a new version at launch&rdquo; in Settings and it makes no connections at all. The [privacy policy](https://elgotune.gigowat.com/privacy.en.html) has been updated to match.

From 1.0.5, Elgotune offers this version at launch.

Signed with a Developer ID and notarized by Apple.
