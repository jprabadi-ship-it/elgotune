## 変更点

- **起動時に新しいバージョンを確認するようにしました**。新しい版があれば、インストールするかを尋ねます。「ダウンロードしてインストール」を選ぶと、ダウンロードと署名の確認を済ませてから Elgotune を一度終了し、新しい版に置き換えて起動し直します。「あとで」「この版はスキップ」も選べます
- ダウンロードした版は、置き換える前に、同じ開発者の Developer ID で署名され、Apple の公証を受けているかを確かめます。条件を満たさない場合や置き換えに失敗した場合は、いまの版をそのまま使います

## 通信についてのお知らせ

これまで Elgotune はネットワーク通信を一切行いませんでしたが、この版から、起動時に GitHub へ最新版の情報を1回問い合わせます。送るのはアプリ名だけで、設定や利用状況は送りません。設定画面の「起動時に新しいバージョンを確認」をオフにすると、通信は一切行いません。[プライバシーポリシー](https://elgotune.gigowat.com/privacy.ja.html)も合わせて更新しました。

なお、1.0.4 以前の版には更新を確認する機能がないため、1.0.5 へは手動で更新してください。

Developer ID 署名・Apple 公証済み。ダウンロード後そのまま開けます。

## Changes

- **Elgotune now checks for a new version at launch.** If one is available, you are asked whether to install it. Choose Download and Install and it downloads and verifies the update, quits, replaces itself with the new version and opens again. You can also choose Later or Skip This Version
- Before replacing anything, the download must be signed with the same developer&rsquo;s Developer ID and notarized by Apple. If it is not, or the replacement fails, the current version keeps running

## About network use

Until now Elgotune made no network connections. From this version it asks GitHub once at launch for the latest release. Only the app&rsquo;s name is sent &mdash; no settings or usage. Turn off &ldquo;Check for a new version at launch&rdquo; in Settings and it makes no connections at all. The [privacy policy](https://elgotune.gigowat.com/privacy.en.html) has been updated to match.

Versions 1.0.4 and earlier cannot check for updates, so please update to 1.0.5 manually.

Signed with a Developer ID and notarized by Apple.
