## 変更点

- **Finder でも戻る・進むボタンが効くようにしました**。Finder はマウスの戻る・進むボタンに反応しないため、Finder が前面のときだけ ⌘[ / ⌘] を送ります。ほかのアプリではこれまでどおりマウスボタンとして送ります

Developer ID 署名・Apple 公証済み。ダウンロード後そのまま開けます。

## Changes

- **Back and forward now work in Finder.** Finder ignores the mouse back and forward buttons, so while it is frontmost the app sends ⌘[ / ⌘] instead. Every other app still receives them as mouse buttons

Signed with a Developer ID and notarized by Apple.
