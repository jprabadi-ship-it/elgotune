できること

Logitech の設定ソフトが対応していない操作も、トラックボール本体の機能として設定できます。

すべてのボタンを割り当て

精密モード、左右・中クリック、戻る／進む、ホイールの左右チルト、デバイス切替。接続中の機種が持つボタンだけが表示されます。

短押しと長押しで別々の操作

1つのボタンに2つの機能。長押しの判定時間は 100〜1500ms の範囲で調整できます。

押しながら転がしてスクロール

ボタンを押している間、ボールの回転を縦横スクロールに変換します。ホイールに手を移さずに長い文書を送れます。

方向ジェスチャー

押しながら上下左右に転がして、4方向それぞれに別の操作を割り当て。デスクトップ切り替えやタブ移動に。

慣性スクロール

ホイールを止めたあとも滑らかに流れ続けます。滑走の長さと初速は好みに合わせて調整でき、次の操作で即座に止まります。

ポインタの速度と加速

デバイス単位で解像度と加速カーブを設定。macOS のスライダーでは届かない範囲まで、細かく詰められます。

アプリ別に無効化

ゲームや配信ソフトなど、標準動作のままにしたいアプリを登録。そのアプリが前面にある間だけ自動で無効になります。

キーボードショートカット

任意のキー組み合わせをボタンに割り当て。Mission Control やアプリケーションウインドウなども選べます。

設定の書き出しと読み込み

すべての設定を JSON ファイルで保存・復元。Mac を移行するときも設定を作り直す必要がありません。

よくある質問

Logi Options+ と併用できますか？

同じボタンを両方から制御すると競合します。Spintune を使う場合は Logi Options+ を終了することをおすすめします。Spintune のカスタマイズを無効にすると、ボタンは本体の標準動作に戻ります。

アプリを終了したら設定はどうなりますか？

終了時に、ポインタの設定もボタンの割り当ても、macOS の標準状態へ自動的に戻します。アンインストールしても設定が残り続けることはありません。

他社製のマウスも使っていますが影響しますか？

中クリック・戻る／進む・チルト・精密モードは対応機種にのみ適用されます。ただし左右クリックの割り当てだけは、macOS のイベントにデバイスの区別がないため、接続中の他のマウスにも適用されます。左右クリックを標準のままにしておけば影響はありません。

2台のトラックボールを同時に使えますか？

使えます。両方のボタンが同時に機能し、バッテリー残量もそれぞれ表示されます。ただし割り当て設定はデバイス共通です。

macOS のアップデートで動かなくなりませんか？

ポインタの速度と加速の調整には、macOS が公開していない仕組みを使っています。将来の macOS で利用できなくなる可能性があり、その場合はポインタ調整機能のみが無効になります（アプリの他の機能と起動には影響しません）。判明し次第、対応版を配布します。
