What it does

Reach the controls Logitech’s own software leaves out, and treat them as first-class buttons.

Remap every button

Precision button, left, right and middle click, back and forward, wheel tilt, Easy-Switch. Only the buttons your connected device actually has are offered.

Two actions per button

A short press and a press-and-hold can do different things. The hold threshold is adjustable from 100 to 1500 ms.

Hold and roll to scroll

While a button is held, ball movement becomes vertical and horizontal scrolling — no need to move your finger to the wheel.

Direction gestures

Hold a button and roll up, down, left or right for four more actions. Ideal for switching desktops or moving between tabs.

Momentum scrolling

Long documents keep gliding after the wheel stops. Tune how far and how fast it coasts; any input stops it instantly.

Pointer speed and acceleration

Set resolution and the acceleration curve per device, well past the range the macOS slider can reach.

Per-app opt-out

List the apps that should keep stock behaviour — games, streaming tools — and customization switches itself off while they are frontmost.

Keyboard shortcuts

Assign any key combination to a button, alongside Mission Control, Application Windows, Show Desktop and more.

Export and import

Save every setting to a JSON file and restore it later — no rebuilding your setup on a new Mac.

Questions

Can I run it alongside Logi Options+?

Driving the same button from both conflicts, so quit Logi Options+ while using Spintune. Turning Spintune’s customization off returns every button to its stock behaviour.

What happens to my device when I quit?

Quitting restores the pointer values and every button to the macOS defaults, so nothing is left behind if you uninstall.

I also use a mouse from another brand. Is it affected?

Middle click, back and forward, wheel tilt and the precision button apply only to supported devices. Left and right click assignments are the exception: macOS events carry no device identity, so those apply to any connected mouse. Leave left and right click at their defaults and nothing else is affected.

Can I use two trackballs at once?

Yes. Both sets of buttons work simultaneously and both battery levels are shown. Assignments are shared across devices.

Will a macOS update break it?

Pointer speed and acceleration rely on an interface Apple does not document. A future macOS could withdraw it, which would disable pointer tuning only — the rest of the app and its launch are unaffected. An updated build follows as soon as that happens.
